# Lemie〜レミエ〜

GitHub Pages向けの静的ホームページです。ビルド・有料サービス・APIキーは不要です。

## 公開

リポジトリの Settings → Pages → Build and deployment で Source を Deploy from a branch、Branch を main、フォルダーを /(root) にして Save。

## 編集

文章は index.html、デザインは style.css を編集します。商品画像は公式BASEショップの画像URLを使用しています。ペライチには依存しません。

## 情報源

https://egaoselect.base.shop/ （2026-11-07確認）。価格、容量、商品リンク、使用方法を確認。定期便の条件は変更に備えてショップでの確認に誘導しています。

## 構成

- index.html: 商品紹介、使い方、FAQ、BASE購入導線
- style.css: スマートフォン対応デザイン
- favicon.svg: サイトアイコン
- .nojekyll: 静的ファイルをそのまま配信
